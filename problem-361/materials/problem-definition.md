# Erdős Problem 361 - 完整问题定义

## 问题陈述

对于固定的 c > 0 和大整数 n，定义：

F_c(n) = max {|A| : A ⊆ {1,...,⌊cn⌋}, n ∉ Σ(A)}

其中 Σ(A) 是 A 的所有子集和的集合（包括空集，和为 0）。

## 目标

找到 F_c(n) 的精确公式（或渐近公式）。

## 关键观察

1. **Admissible 集合**: 如果 n ∉ Σ(A)，则称 A 为 admissible 的
2. **约束条件**: A ⊆ {1,...,⌊cn⌋}
3. **目标**: 最大化 |A|

## 已知结果

### c ≥ 1 的情况

**猜想**: F_c(n) = ⌊cn⌋ - ⌈n/2⌉

**构造**: 取 A = {⌈n/2⌉, ⌈n/2⌉+1, ..., ⌊cn⌋} \ {n}

**证明思路**:
1. 这个集合是 admissible 的（下界）
2. 任何更大的集合都不是 admissible 的（上界）

### c < 1 的情况

**猜想**: F_c(n) = max over k≥2 of (⌊n/k⌋ - ⌈n/(k+1)⌉)

其中 k 满足：
1. k ≥ 2
2. k ∤ n
3. ⌈n/(k+1)⌉ ≤ ⌊cn⌋

**构造**: 取 A = {⌈n/(k+1)⌉, ⌈n/(k+1)⌉+1, ..., ⌊n/k⌋}

**证明思路**:
1. 这个集合是 admissible 的（下界）
2. 任何更大的集合都不是 admissible 的（上界）

## 证明策略

### 下界（存在性）

对于给定的 k，构造一个 admissible 集合 A，使得 |A| = ⌊n/k⌋ - ⌈n/(k+1)⌉ + 1

### 上界（最优性）

证明任何大小超过 ⌊n/k⌋ - ⌈n/(k+1)⌉ + 1 的集合都不是 admissible 的

### 关键引理

1. **配对引理**: 如果 x + y = n，则 A 不能同时包含 x 和 y
2. **区间引理**: 如果所有元素都在 [⌈n/(k+1)⌉, ⌊n/k⌋] 中，则：
   - 任何 ≤ k 个元素的和 < n
   - 任何 ≥ k+1 个元素的和 > n
3. **整除引理**: 如果 k | n，则 k 个 n/k 的和 = n，因此 A 不能包含 k 个 n/k
