# Erdős Problem 361 Workspace

This folder collects the working material for Erdős Problem #361 and is set up for iterative proof attempts with Claude or another proof-writing model.

## Problem

For fixed `c > 0` and large integer `n`, determine the maximum size of a set

```tex
A \subseteq \{1,\ldots,\lfloor cn\rfloor\}
```

such that `n` is not a sum of a subset of `A`. The Erdős Problems page also asks whether the answer depends on `n` irregularly.

Status on erdosproblems.com as checked on 2026-05-21: open.

## Files

- `materials/source-summary.md`: statement, source links, comments, and extracted heuristics.
- `materials/problem-361.lean`: Lean formal-conjectures statement copied from the public raw file, with license header retained.
- `materials/research-directions.md`: proof targets, constructions, and review checklist.
- `proof-log/`: place for iterative attempts and reviews generated by the proof-loop skill or script.

## Suggested First Target

Do not try to prove the full open problem in one jump. A first exact lemma for `c >= 1` is written in `proof-log/verified-lemma-c-ge-1.md`. Continue with rigorous bounds for concrete ranges of `c`, especially:

- `1/2 < c < 1`, where the comments suggest an upper bound near `cn/2 + O(1)`.
- `c = 3/4`, where available comments report irregular computational behavior and modular constructions.
